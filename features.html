Features

Comprehensive transport property analysis capabilities

Supported Simulation Engines

GROMACS

  • Trajectory formats: .xtc, .trr, .gro, .pdb
  • Topology: .tpr, .itp, .top
  • Binary file support via MDAnalysis, Chemfiles, OVITO
  • Automatic residue detection from .gro/.pdb/.tpr/.itp
  • --t_steps maps to GROMACS -dt flag

LAMMPS

  • Trajectory formats: .lammpstrj, .xtc, .dcd
  • Data files: .data, .in
  • --t_steps = LAMMPS timestep; --dump_frame = dump frequency
  • MDTransport computes dt = t_steps × dump_frame
  • Species identification via atom types or molecule IDs

Transport Properties Computed

--msd

Self-Diffusion Coefficients

  • COM-based MSD for each molecule (Eq. 1–4)
  • Direction-specific: --dir x, --dir x y, or 3D (default)
  • Per-species: --resname flag
  • Intramolecular fragments: --msd_mode --msd_species
  • FFT-accelerated autocorrelation
  • Adaptive fitting for diffusion regime
  • Uncertainty via block averaging, time-window variation
--ne

Nernst-Einstein Conductivity

  • σNE = (1/VkBT) Σ Nizi2Di (Eq. 6)
  • Ideal conductivity (no ion-ion correlations)
  • Uses self-diffusion coefficients from MSD
  • Quick screening for correlation effects
--corr

Einstein Ionic Conductivity

  • Full Einstein formalism (Eq. 7)
  • Self- and cross-correlation decomposition (Eq. 8)
  • Intercomponent (C–A) & intracomponent (C–C, A–A)
  • Slope over first 1 ns (configurable: --min_window)
  • Multiple time origins for averaging
--corr --eh

Einstein-Helfand Conductivity

  • Dipole moment of entire species (bypasses pairwise sum)
  • Orders of magnitude faster for large systems
  • Enables full trajectory sliding windows
  • Identical results to standard Einstein
--spda

Spatial Decomposition (SPDA)

  • σproximal (r < rcut) & σdistant (r > rcut) (Eq. 16–17)
  • Auto rcut from 2nd RDF minimum
  • Manual override: --shell or --rcut
  • Three ion subsets: inside, outside, jumping
  • Molecular-level insight for electrolyte design
--onsg

Onsager Transport Coefficients

  • Cross-species transport coefficients Lij
  • Standard Einstein & EH formalism (--onsg --eh)
  • EH: collective displacement variables
  • Full trajectory windows feasible with EH
--corr

Transference Numbers

  • Ideal: tiideal = Nizi2Di / Σ (Eq. 23)
  • Real: includes self + cross correlations (Eq. 24)
  • Computed alongside Einstein conductivity
--sm

Stefan-Maxwell Diffusivity

  • Dij for species pairs (Eq. 25)
  • COM displacement differences
  • Multicomponent diffusion analysis
--cage

Cage Correlation Lifetimes

  • Heaviside function tracking (Eq. 28)
  • Cage = 1st solvation shell from RDF
  • Reformation allowed: h(t) can return to 1
  • τcage via integration or 3-exponential fit (Eq. 30–31)
  • Requires --ref_species --cage_species
--pair

Pair Correlation Lifetimes

  • Nearest-neighbor tracking (Eq. 32)
  • Heaviside step function
  • Reformation allowed
  • 3-exponential fit for τpair
  • Requires --ref_species --pair_species
--cluster

Cluster Analysis

  • Ion clustering statistics
  • Cluster size distributions
  • Percolation analysis
--rdf

Radial Distribution Functions

  • COM-COM (default), atom-atom, atom-COM
  • Standard formula (Eq. 37)
  • Targeted pairs: --resname EMI BF
  • Custom sites: --rdf_mode --rdf_pairs
  • Auto-analysis: --ana (peaks, coordination number, shell radii)
--mech

Transport Mechanism

  • Ion transport mechanism classification
  • Vehicle vs. structural diffusion
  • Hopping analysis

Three Interfaces

Prompt-Based CLI

Designed for HPC environments. Stepwise prompts guide new users; experts use single-command flags.

$ mdt > Select analysis: 1) MSD 2) Conductivity 3) RDF... > Enter trajectory file: traj.xtc > Enter topology: topol.tpr > Time step (ps): 20
  • Interactive prompts with validation
  • All flags available for scripting: mdt --msd --corr -t traj.xtc ...
  • Help: mdt -h | Examples: mdt -e

Desktop Application

Cross-platform GUI for local execution. Same engine, visual workflow builder.

  • Visual parameter configuration
  • Real-time progress monitoring
  • Plot preview and export
  • Available at shahresearchgroup.org

Web Interface

Browser-based analysis — upload trajectories, configure analysis, download results.

  • No installation required
  • Cloud compute or local browser processing
  • Session persistence
  • Available at shahresearchgroup.org

Advanced Computational Features

Adaptive Fitting

Automated detection of diffusive regime reduces user bias in time-window selection for MSD and conductivity slope calculations.

Multi-Tool Backend

Switch between MDAnalysis, Chemfiles, OVITO, or native GROMACS/LAMMPS via flags: --mda, --chem, --ovito, --exe. Binary format support without conversion.

Disk-Backed Processing

--disk flag streams intermediate data to disk, reducing peak memory ~50% for large systems. Trade-off: I/O overhead on HDD.

Multiprocessing

Uses all cores by default. Control via --n_cores and --mp_mode (spawn/fork/forkserver). Optimized for resource-constrained environments.

PBC Handling

Two-step: (1) minimum-image reconstruction of fragmented molecules, (2) displacement correction for boundary-crossing jumps.

Selective COM Extraction

Atomic coordinates for RDF/MSD of fragments; COM for bulk properties. Flags: --pdb, --lamp, --exe, --mda, --chem, --ovito.
