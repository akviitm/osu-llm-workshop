Key Capabilities

Multi-Engine Support

Process trajectories from both GROMACS and LAMMPS with a unified interface. No need to learn multiple tools.

Three Interfaces

Prompt-based CLI for HPC, cross-platform desktop app, and cloud web interface — choose what fits your workflow.

Comprehensive Properties

Self-diffusion, ionic conductivity (Einstein & Nernst-Einstein), Onsager coefficients, transference numbers, and more.

Advanced Analyses

Ion-ion correlations, spatial decomposition (SPDA), cage/pair correlation lifetimes, cluster analysis, transport mechanisms.

Modular Architecture

Engine-independent calculation algorithms. Each property module is a self-contained class for easy extension.

Open Source (GPL)

Free to use, modify, and distribute. Hosted on GitHub with comprehensive documentation and example data.

Quick Start

1

Install

pip install MDTransport

Or via Conda: conda install -c conda-forge mdtransport

2

Run Interactive CLI

mdt

Follow prompts to select analysis type, trajectory, and parameters.

3

Or Run Directly

mdt --msd --corr --ne --rdf \
  --traj trajectory.xtc \
  --top topology.tpr \
  --t_steps 20
