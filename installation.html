Installation

Multiple deployment options for diverse environments

Quick Install

PyPI (pip)

Recommended 
pip install MDTransport

Installs the latest stable release with all core dependencies.

Conda (conda-forge)

conda install -c conda-forge mdtransport

Best for conda environments; handles non-Python dependencies automatically.

Development (editable)

git clone https://github.com/ShahResearchGroup/MDTransport.git
cd MDTransport
pip install -e .

For contributors or testing latest changes. Links source directly.

Alternative Deployment

Desktop Application

Cross-platform GUI installer for Windows, macOS, Linux. No command-line needed.

Download from Shah Research Group

Web Interface

Browser-based — no installation. Upload trajectories, run analysis, download results.

Run from Source (no install)

Execute directly from cloned repository without PyPI/Conda installation.

git clone https://github.com/ShahResearchGroup/MDTransport.git
cd MDTransport
python mdt.py

Prerequisites

Core Python Packages

  • numpy ≥ 1.21
  • scipy ≥ 1.7
  • pandas ≥ 1.3
  • matplotlib ≥ 3.4
  • tqdm ≥ 4.62

All installed automatically via pip/conda.

Optional Backend Libraries

For enhanced binary format support, multiprocessing, and memory efficiency:

  • MDAnalysis — pip install MDAnalysis
  • chemfiles — pip install chemfiles
  • ovito — conda install -c conda-forge ovito

MDTransport auto-detects available backends. Flags: --mda, --chem, --ovito, --exe.

System Requirements

  • Python ≥ 3.8
  • Linux / macOS / Windows
  • Multi-core CPU recommended
  • RAM: 4 GB minimum; 16 GB+ for large trajectories

Run Example

cd MDTransport/sample
mdt --msd --ne --rdf \
  --traj gromacs/traj.xtc \
  --top gromacs/topol.tpr \
  --t_steps 20

Sample data included in repo (sample/gromacs/, sample/lammps/).

mdt -e

HPC / Cluster Installation

Module-based Environments

# Load Python and create virtual environment
module load python/3.10
python -m venv mdt_env
source mdt_env/bin/activate
pip install MDTransport

# Optional: install backends
pip install MDAnalysis chemfiles

Container (Docker/Singularity)

# Docker
docker run -it python:3.10-slim bash -c "pip install MDTransport && mdt -h"

# Singularity (HPC-friendly)
singularity pull docker://python:3.10-slim
singularity exec python_3.10.sif pip install MDTransport

Environment Variables

# Control multiprocessing
export MDT_N_CORES=8
export MDT_MP_MODE=forkserver  # or spawn, fork

# Enable disk-backed mode by default
export MDT_DISK=1

Troubleshooting

ImportError: No module named 'MDTransport'

Ensure you're using the same Python environment where you installed. Check with pip list | grep MDTransport. For conda, use conda list mdtransport.

Trajectory format not supported (.xtc, .trr, .lammpstrj)

Install MDAnalysis, chemfiles, or ovito. MDTransport auto-detects: pip install MDAnalysis chemfiles. For OVITO on Linux: conda install -c conda-forge ovito.

MemoryError on large trajectories

Use --disk flag for disk-backed processing. Reduce --n_cores. Use binary formats (.xtc) with MDAnalysis/chemfiles for lower memory.

Multiprocessing hangs or fails

Try --mp_mode spawn (default on Windows/macOS) or --mp_mode forkserver. Reduce --n_cores. Some HPC systems require spawn.

GROMACS .tpr topology not read

Ensure GROMACS is in PATH for native parsing, or install MDAnalysis: pip install MDAnalysis. Use --mda flag to force MDAnalysis backend.

LAMMPS timestep/dump frame confusion

For LAMMPS: --t_steps = integration timestep (e.g., 1 fs = 0.001 ps), --dump_frame = dump frequency. MDTransport computes dt = t_steps × dump_frame. All time params in ps.
