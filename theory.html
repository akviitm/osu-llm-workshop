Theoretical Background

Mathematical foundations for transport property calculations

Mean-Squared Displacement (MSD)

The mean-squared displacement for a group of Nk entities (atoms, molecules, or fragments) is defined as:

Eq. 1 
MSD(Δt) = (1/Nk) Σi=1Nk ⟨|ric(t+Δt) - ric(t)|2⟩

Where ric is the center-of-mass position of the i-th entity, and ⟨···⟩ denotes time averaging over all origins t. The dimensionality d defaults to 3 (x, y, z) but can be restricted to 1D or 2D via the --dir flag for anisotropic systems (nanotubes, slab geometries).

FFT-Accelerated Computation

Expanding the squared displacement yields three terms (Eq. 3):

Eq. 3 
|r(t+Δt) - r(t)|2 = |r(t+Δt)|2 + |r(t)|2 - 2 r(t+Δt)·r(t)

The third term is the time-autocorrelation of the position vector, computed efficiently via Fast Fourier Transform (FFT) following Fong et al. (2017). The final MSD expression (Eq. 4) becomes:

Eq. 4 
MSD(Δt) = (1/Nk) Σi=1Nk [ ⟨|ric(t+Δt)|2⟩ + ⟨|ric(t)|2⟩ - 2 ⟨ric(t+Δt)·ric(t)⟩ ]

Self-Diffusion Coefficient

In the diffusive regime (long times), MSD grows linearly:

Eq. 2 
MSD(Δt) = 2d D Δt

MDTransport evaluates the diffusion regime over a user-defined time window. The slope is determined via adaptive fitting (linear regression with automatic window selection) to minimize bias. Uncertainty is quantified via block averaging, time-window variation, and ensemble approaches.

Ionic Conductivity

Nernst-Einstein Conductivity

The ideal conductivity assumes uncorrelated ion motion:

Eq. 6 
σNE = (1/VkBT) Σi Ni zi2 Di

Where V = volume, kB = Boltzmann constant, T = temperature, Ni = number of ions of species i, zi = charge, Di = self-diffusion coefficient.

Einstein Conductivity (Full Correlation)

Accounts for ion-ion correlations via collective charge displacement:

Eq. 7 
σEN = limt→∞ (1/2VkBT) ⟨ [ Σi,j zizj (ric(t) - ric(0))·(rjc(t) - rjc(0)) ] ⟩ / t

Decomposes into self (i=j) and cross-correlation (i≠j) contributions. For a salt [C][A]:

Eq. 8 
σEN = σ[C]self + σ[A]self + σ[C]-[C]cross + σ[A]-[A]cross + σ[C]-[A]cross

The first two terms sum to σNE. The cross terms reveal correlation effects: negative cross-correlation reduces conductivity (ion pairing), positive enhances it (collective motion).

Slope Method

The correlation term C(t) = Σ zizj Δri·Δrj is plotted vs. time. The slope over the first 1 ns (configurable via --min_window) gives σEN. Multiple time origins improve statistics.

Einstein-Helfand (EH) Formalism

Uses the total dipole moment of each species, bypassing pairwise sums:

Mα(t) = Σi∈α zi ric(t)
σEH = limt→∞ (1/2VkBT) ⟨ |M(t) - M(0)|2 ⟩ / t

Computational cost: O(N) vs O(N2) for standard Einstein. Enables full-trajectory sliding windows. Enabled via --corr --eh.

Spatial Decomposition Analysis (SPDA)

Decomposes cross-correlations by distance from a reference ion. Ions are categorized by distance rcut from reference:

Eq. 16 
σproximal = limt→∞ (1/2VkBT) Σi Σj: rij<rcut zizj ⟨Δri·Δrj⟩ / t
Eq. 17 
σdistant = limt→∞ (1/2VkBT) Σi Σj: rij>rcut zizj ⟨Δri·Δrj⟩ / t

Three ion subsets around each reference: always inside, always outside, jumping across rcut. Default rcut = 2nd RDF minimum (2nd solvation shell). Override with --shell (1st shell) or --rcut (custom).

Onsager Transport Coefficients

Generalized transport coefficients for multicomponent systems:

Eq. 18–22 
Lαβ = limt→∞ (1/2VkBT) ⟨ [Σi∈α zi Δri]·[Σj∈β zj Δrj] ⟩ / t

Standard Einstein requires O(N2) pairwise cross-displacements. EH formalism (--onsg --eh) uses collective species displacements:

LαβEH = limt→∞ (1/2VkBT) ⟨ [Σi∈α Δri]·[Σj∈β Δrj] ⟩ / t

(No charge weighting in the collective variable; charge factors applied in final combination.) Dramatically reduces cost, enables long sliding windows.

Transference Numbers

Ideal Transference Number

Eq. 23 
tiideal = (Ni zi2 Di) / Σj (Nj zj2 Dj)

Real Transference Number (with correlations)

Eq. 24 
tireal = (σiself + 0.5 σi-icross + Σj≠i σi-jcross) / σEN

Computed alongside Einstein conductivity. σiself = self-diffusion contribution; σi-icross = intracomponent correlation; σi-jcross = intercomponent correlation.

Stefan-Maxwell Diffusivity

Diffusion coefficient for species pair (i, j) in multicomponent systems:

Eq. 25 
MSDij(Δt) = (1/NiNj) Σi=1Ni Σj=1Nj ⟨ |Δric - Δrjc|2 ⟩

Where Δric = ric(t+Δt) - ric(t). Dij obtained from long-time slope of MSDij.

Cage Correlation Lifetimes

A cage around species i is defined by all species j within the 1st solvation shell (RDF first minimum). The Heaviside function tracks identity persistence:

Eq. 28 
Ccage(t) = (1/N(t0)) Σk=1N(t0) hk(t) / hk(0)

h(t) = 1 if cage identity maintained, 0 if any ion enters/exits. Cages can reform. Lifetime via integration or 3-exponential fit:

Eq. 29–31 
τcage = ∫0∞ Ccage(t) dt
Ccage(t) = a1exp(-t/b1) + a2exp(-t/b2) + a3exp(-t/b3)
τcage = a1b1 + a2b2 + a3b3  (with a3 = 1 - a1 - a2)

Flags: --cage --ref_species X --cage_species Y [--rcut Z]

Pair Correlation Lifetimes

For each reference i, identify nearest target species j (minimum COM distance). Track identity over time:

Eq. 32 
Cpair(t) = (1/N(t0)) Σk=1N(t0) hk(t) / hk(0)

h(t) = 1 while same nearest neighbor, 0 if another ion becomes closer. Reformation allowed. τpair via 3-exponential fit. Flags: --pair --ref_species X --pair_species Y [--rcut Z]

Radial Distribution Function (RDF)

Standard definition for species i and j:

Eq. 37 
gij(r) = (V / NiNj) Σi=1Ni Σj=1Nj δ(r - rij) / (4πr2Δr)

Kronecker δ = 1 if rij ∈ [r, r+Δr), else 0. Modes: COM-COM (default), atom-atom, atom-COM via --rdf_mode --rdf_pairs. Auto-analysis (--ana) extracts: 1st peak radius/height, 1st/2nd shell radii, coordination number.
